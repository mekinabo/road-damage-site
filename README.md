# Система обнаружения повреждений дорожного покрытия по изображениям

Проект для научно-образовательного соревнования «Шаг в будущее» (профиль «Инженерное дело»).

Система отмечает на снимке дороги предполагаемые повреждения четырёх видов: продольные трещины (D00), поперечные трещины (D10), сетку трещин (D20) и выбоины (D40). Основа — нейросетевой детектор YOLOv8s, дообученный на снимках дорог Чехии из открытого набора RDD2020. Пользователь работает с системой через веб-сайт на FastAPI.

Главный результат эксперимента: на 310 снимках 149 новых участков дообучение повысило mAP@0,5 с 0,162 (модель M0) до 0,342 (модель M1); прирост 0,181, 95 % доверительный интервал от 0,123 до 0,247. Ложных срабатываний на снимок без повреждений: M0 — 0,12, M1 — 0,48, метод Канни — 4,18.

## Структура папок

| Папка | Что внутри |
|---|---|
| `site/` | веб-сайт: `app.py` (FastAPI + YOLO), страница в `static/`, веса моделей в `models/` (M3 по умолчанию, запасные M1 и M0) |
| `training/` | `prep_czech.py` (группировка снимков по участкам), блокнот эксперимента `experiment1_finetune.ipynb` и он же с результатами, `m2_background/` и `m3_web/` (дополнительные модели M2 и M3) |
| `data/` | `czech_dataset.zip` — подготовленный набор снимков Чехии (1072 снимка с повреждениями, 200 без повреждений, `test_groups.txt`); `found_images/` — снимки G001, G002 |
| `results/` | таблицы результатов эксперимента и снимки-примеры разбора случаев |
| `docs/` | текст работы, техническое задание, презентация и текст выступления |

## Как запустить сайт (Windows)

Нужен Python 3.10 или новее.

```
cd site
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

Затем откройте в браузере http://127.0.0.1:8000. Подробнее — в `site/Как_запустить.md`.

## Как повторить эксперимент

Распакуйте `data/czech_dataset.zip` в папку `training/input/`, положите туда `site/models/m0_rdd2022.pt` и запустите все ячейки `training/experiment1_finetune.ipynb` (на процессоре с 4 ядрами около 2 ч 40 мин; на Kaggle с GPU быстрее).
