# Сайт обнаружения повреждений дороги

Пользователь загружает фото дороги (или фотографирует прямо с телефона), сервер на FastAPI прогоняет его через YOLO, страница рисует рамки вокруг предполагаемых повреждений: продольные (D00) и поперечные (D10) трещины, сетку трещин (D20), выбоины (D40). Ползунок «порог уверенности» меняет, какие рамки показывать, без повторной отправки фото. Результат можно скачать картинкой.

## Запуск на своём компьютере (Windows)

Нужен Python 3.10 или новее (python.org, при установке отметить «Add Python to PATH»). Распакуйте архив `road-damage-site.zip`: веса моделей M1 и M0 уже лежат в папке `models/` внутри папки сайта. Затем в командной строке:

```
cd путь\к\road-damage-site
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

Откройте в браузере http://127.0.0.1:8000. Первая установка занимает 5–10 минут (PyTorch большой), дальше достаточно `venv\Scripts\activate` и `python app.py`.

## Как открыть сайт с телефона и других устройств

**В той же Wi‑Fi сети** (удобно на защите): выполните `set HOST=0.0.0.0`, затем `python app.py`, а на телефоне откройте `http://<IP компьютера>:8000` (IP показывает команда `ipconfig`, строка IPv4). Windows может спросить разрешение для Python в брандмауэре — разрешите для частной сети.

**Из любого места через интернет**: скачайте `cloudflared` (developers.cloudflare.com → Downloads, файл для Windows), запустите сайт как обычно и во втором окне выполните `cloudflared tunnel --url http://localhost:8000`. Программа напечатает адрес вида `https://….trycloudflare.com` — он открывается с любого телефона, планшета и компьютера по защищённому HTTPS. Сайт работает, пока включены компьютер и обе программы.

## Какая модель используется

Сервер ищет веса в папке `models/` рядом с `app.py` (так в архиве), а затем в `models/` уровнем выше, и берёт первую найденную:

1. `models/m3_web.pt` — модель M3: M1 с дополнительным дообучением на 300 снимках Чехии и 25 фотографиях дорог из интернета (эксперимент 1; сейчас используется она);
2. `models/m1_finetuned.pt` — модель M1, дообученная на снимках дорог Чехии из набора RDD2020 (запасная, если нет файла M3);
3. `models/m0_rdd2022.pt` — YOLOv8s, обученная только на RDD2022 (запасная; источник весов — github.com/oracl4/RoadDamageDetection, 22 МБ);
4. `yolov8s.pt` — общая модель COCO, о дорогах не знает; сайт покажет предупреждение.

Другую модель можно указать явно: `set MODEL_PATH=C:\путь\к\best.pt`, затем `python app.py`.

## Защита и устойчивость

- Принимаются только изображения (JPG, PNG, WEBP, HEIC с iPhone и др.): формат проверяется по содержимому файла, а не по названию. Предел — 20 МБ и 25 мегапикселей (любой телефон снимает меньше); слишком большие и слишком медленные загрузки обрываются, не дожидаясь конца. Раскодируется не больше двух фото одновременно, поэтому сервер не падает от нехватки памяти.
- Не больше 30 анализов в минуту с одного адреса. Модель обрабатывает фото по очереди; при перегрузке сервер отвечает «занят», а страница сама повторяет попытку.
- Заголовки безопасности: строгая политика CSP (только свои скрипты и стили), запрет встраивания сайта в чужие страницы, `nosniff`, `no-referrer`, HSTS при работе по HTTPS.
- Ошибки сервера пишутся в журнал, а пользователю показывается понятное сообщение по-русски без технических подробностей. Фото не сохраняются на диск.
- Перед отправкой большое фото уменьшается в браузере до 1600 px, поэтому загрузка через мобильный интернет идёт в разы быстрее.

Настройки через переменные окружения (`set ИМЯ=значение` перед `python app.py`): `HOST`, `PORT`, `MAX_UPLOAD_MB`, `RATE_PER_MIN`, `MODEL_PATH`, `DOCS=1` (включает страницу `/docs` с описанием API).

## API

- `POST /api/detect` — поле `file` с фото; ответ: размер снимка, время анализа и список `detections` (`code`, `name`, `conf`, `box` в пикселях, `frame_share` — сколько процентов кадра занимает рамка).
- `GET /api/model` — какая модель загружена; `GET /api/health` — проверка, что сервер жив.

Сайт находит предполагаемые повреждения, но не измеряет их. `frame_share` — это не площадь ямы: в квадратные метры её без масштаба снимка не перевести, а для вывода по ГОСТ Р 50597-2017 нужна ещё и глубина. Площадь будет проверяться отдельно, на выбоинах с ручными замерами.
